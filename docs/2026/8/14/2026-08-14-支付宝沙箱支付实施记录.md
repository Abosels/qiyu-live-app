# 支付宝沙箱支付实施记录

## 本次实现

- `qiyu-live-api` 创建充值订单后，支付宝渠道返回 `payUrl`，浏览器跳转到 `qiyu-live-bank-api`。
- `qiyu-live-bank-api` 使用支付宝 Java SDK 生成电脑网站支付表单，并提供 `/payNotify/alipay-notify` 异步回调入口。
- 回调先验证签名、`app_id`、订单金额和支付渠道，再调用 `bank-provider` 的既有幂等入账逻辑。
- `t_pay_order` 新增订单金额、金币数量和第三方交易号快照。入账只使用快照，产品后续改价不影响已创建订单。
- 微信仍保留 Mock 回调，未接入真实微信支付。

## 你需要手动完成

1. 在 `qiyu_live_bank` 执行 `V20260814__add_pay_order_snapshot_for_alipay.sql`。
2. 将 `docs/nacos-configs/qiyu-live-bank-api.yml` 的支付宝沙箱配置上传或合并到 Nacos。
3. 填写沙箱 `app-id`、应用私钥、支付宝公钥；不要提交这些值到 Git。
4. 用内网穿透提供可公网访问的 HTTPS `notify-url`，地址必须指向 `/payNotify/alipay-notify`。
5. 重启 `bank-provider`、`bank-api` 和 `qiyu-live-api`。

## 联调顺序

1. 调用 `/bank/payProduct`，传 `payChannel=0`，获取 `orderId` 与 `payUrl`。
2. 浏览器打开 `payUrl`，使用支付宝沙箱买家账号支付。
3. 支付宝异步通知成功后检查 `t_pay_order.status=2`、`third_party_trade_no` 已填写、余额和交易流水各增加一次。
4. 同一订单重复回调，余额与交易流水不应重复增加。
