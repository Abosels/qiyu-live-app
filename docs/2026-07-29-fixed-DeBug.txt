一、严重 Bug 修复 (4项)
================================================================================

1. AccountTradeRespDTO.buildSuccess() 设置 isSuccess=false
   文件: qiyu-live-bank-interface/src/main/java/org/qiyu/live/bank/dto/AccountTradeRespDTO.java
   行号: 35
   问题: buildSuccess() 方法内 dto.setSuccess(false)，导致扣款成功后返回 isSuccess=false
   影响: SendGiftConsumer 中 if (tradeRespDTO.isSuccess()) 永远为 false，
         用户余额被扣但永远收到"送礼失败"的 IM 通知
   修复: dto.setSuccess(false) → dto.setSuccess(true)

2. PayTopicServiceImpl.getByCode() 直接返回 null（未实现）
   文件: qiyu-live-bank-provider/src/main/java/org/qiyu/live/bank/provider/service/impl/PayTopicServiceImpl.java
   行号: 27
   问题: 方法体只有 return null，未实现任何查询逻辑
   影响: PayOrderServiceImpl.payNotify() → getByCode() → return null → 直接 return false
         → payNotifyHandler() 永远不会执行 → 充值回调后用户余额永远不会增加！
   修复: 参照 getPayTopicById() 实现，用 LambdaQueryWrapper 按 bizCode 和 status 查询

3. GiftController.sendGift() 未调用 service
   文件: qiyu-live-api/src/main/java/org/qiyu/live/api/controller/GiftController.java
   行号: 43
   问题: 直接 return WebResponseVO.success()，giftService.sendGift() 从未调用
   影响: 整个送礼链路从 HTTP 入口就断了，MQ 消息不会发送，余额不会扣减
   修复: return WebResponseVO.success(giftService.sendGift(giftReqVO))

4. GiftRecordRpcImpl 注入注解错误
   文件: qiyu-live-gift-provider/src/java/org/qiyu/live/gift/provider/rpc/GiftRecordRpcImpl.java
   行号: 12
   问题: 使用 org.springframework.data.annotation.Reference 注入 Service
         (这是 Spring Data 的关联注解，不是 IoC 容器注入注解)
   影响: giftRecordService 不会被注入，调用时 NPE
   修复: import jakarta.annotation.Resource + @Resource 替换 @Reference

================================================================================

9. GiftConfigServiceImpl.queryGiftList() 误加 limit 1
   文件: qiyu-live-gift-provider/src/java/org/qiyu/live/gift/provider/service/impl/GiftConfigServiceImpl.java
   行号: 35
   问题: 查询全部礼物列表时 queryWrapper.last("limit 1") 限制了只返回一条
   修复: 删除 queryWrapper.last("limit 1")
   注意: getGiftId() 中的 limit 1 是正确的（查单个），保留不动

10. OrderStatusEnum 拼写错误
    文件: qiyu-live-bank-interface/src/main/java/org/qiyu/live/bank/constants/OrderStatusEnum.java
    行号: 10
    问题: PAYED(2,"已付中") → 应为 "已支付"
    修复: "已付中" → "已支付"

11. GiftServiceImpl.sendGift() 死代码注释保留
    文件: qiyu-live-api/src/main/java/org/qiyu/live/api/service/impl/GiftServiceImpl.java
    行号: 72-74
    问题: AccountTradeReqDTO reqDTO 创建后从未使用（扣款已改为 MQ 异步模式）
    修复: 按旧代码保护规则注释保留，标注原因

12. consume() 方法补全 Redis 同步 + 交易流水
    文件: qiyu-live-bank-provider/src/main/java/org/qiyu/live/bank/provider/service/impl/QiyuCurrencyAccountServiceImpl.java
    问题: consume() 的 DB 原子扣减成功后:
          (1) Redis 缓存未同步 → getBalance() 读到过期旧值
          (2) 交易流水未插入 → t_qiyu_currency_trade 无记录
    修复:
          (1) DB 扣减成功后同步 decrement Redis 缓存
          (2) 通过异步线程池插入交易流水记录(最终一致性，与 decrease() 策略一致)
