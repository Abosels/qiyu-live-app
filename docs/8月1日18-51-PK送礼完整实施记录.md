## 核心不变量

1. `SendGiftMQ.uuId` 是整条送礼链路唯一业务号
2. `t_qiyu_currency_trade.biz_id` = `t_pk_score_record.biz_id` = `SendGiftMQ.uuId`
3. 资金幂等 ≠ PK 计分幂等，各层独立幂等
4. PK 公共事件双房间广播，普通弹幕只发当前房间
5. 实时比分以 Redis 为准，最终结算以 MySQL 汇总为准
